# eCommerce Cacau Show | CoderHouse
Este Proyecto fue creado en curso React.Js en Coder House para colocar en practica los conocimientos en creacion de componentes, construir una aplicasion SPA, base de datos, estados y librerias

![alt](/public/portada-img.png)

## Instalacion
1. Clone el [repositorio](https://github.com/juanma-hinojosa/creaTuLandingJuanHinojosa.git)
2. Abra la carpeta `creaTuLanding+Hinojosa`
3. Ejecute el comando `npm install`, para instalar dependencias y crear la carpeta `node_modules`
4. Ejecute el comando `npm run dev` para levantar la app en un entorno local.

## Librerias Utilizadas
- [React Router Dom](https://reactrouter.com/): Libreria usada para el manejo de rutas como SPA
- [React Toastify](https://fkhadra.github.io/react-toastify/introduction): Libreria Utilizada para la confirmacion de eventos
- [Iconify](https://iconify.design/): Libreria de iconos
- [SwiperJS](https://swiperjs.com/): Libreria de animaciones del tipo Swipper
- [FireBase](https://firebase.google.com/?hl=es-419): Base de datos implementada para los documentos de productos del sitio web
- [React Hook Form](https://react-hook-form.com/): validacion del formulario
- [React Loading Skeleton](https://www.npmjs.com/package/react-loading-skeleton): Libreria usada para render de Skeleton
